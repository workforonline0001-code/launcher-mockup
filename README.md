# Launcher Prototype

This is a static mockup for the campaign launcher UI.

## Open in browser
1. Save the files in one folder.
2. Open `index.html` directly in browser.
3. Or run:
   python3 -m http.server 8000
   then open http://localhost:8000

## Included screens
- Dashboard
- Templates
- New Launch Wizard
- Creative Library
- Monitor / Launch Queue
- Problems / Action Center
- Settings
- AI Helper

## Notes
- This is a mockup only; no real Meta API calls.
- It is designed to be modified into a working frontend.
- Styling is Meta + Google Ads inspired.
